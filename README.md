# 🏛️ نقشه سه‌بعدی دانشکده برق و کامپیوتر

نقشه‌ی تعاملی و سه‌بعدی ساختمان‌های دانشکده‌ی برق و کامپیوتر دانشگاه صنعتی اصفهان؛ برای پیدا کردن سریع دفتر اساتید، آزمایشگاه‌ها و کلاس‌ها.

**🔗 نسخه‌ی آنلاین:** https://maktulism.github.io/IUT_CE-3D-map/
## ✨ امکانات
- نمای سه‌بعدی ساختمان‌ها؛ با لمس یا ماوس بچرخانید و زوم کنید.
- انتخاب هر طبقه برای دیدن اتاق‌ها و فهرست آن‌ها به ترتیب از پله تا انتهای راهرو.
- جستجوی استاد، اتاق یا آزمایشگاه.
- کلیک روی دفتر هر استاد: عکس، ایمیل، تلفن، صفحه‌ی شخصی و زمینه‌های پژوهشی.
- «پل ارتباطی» بین دو دانشکده با ویدیوی معرفی دانشکده.
- حالت شب و روز،چهار فصل پاییز زمستان بهار و تابستان سازگار با موبایل و دسکتاپ.
## 🧩 فناوری
HTML و CSS و جاوااسکریپت خالص، به‌همراه [three.js](https://threejs.org) برای رندر سه‌بعدی.

## 📌 نکته
اطلاعات اساتید از صفحه‌ی «افراد» سایت دانشکده برداشته شده است؛ ممکن است با گذشت زمان تغییر کند.
